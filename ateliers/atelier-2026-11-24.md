## Circuit de chaque standard
- **Groupe :** Steward (rédaction) → Croisement B→A → Croisement A→B → Agent DPO → Leader (C1-C7, toutes les fiches) → Owner (dossier) → **Data Owner humain**.
- **Bis :** Manager (rédaction) → Croisement B→A → Croisement A→B → Agent DPO (tri par criticité)
  - critique : Leader bis (C1-C7) → **Data Governance Leader humain** (confirmation) → Data Manager ;
  - non critique : Manager (dossier) → **Data Manager humain**.

## Décisions prises
- Les deux sens du croisement sont deux agents distincts et parallèles (B→A : terme → colonnes ; A→B : colonne → terme).
- La classification est confiée à un **agent DPO** dans chaque standard. **Règle d'héritage :** le terme métier porte la
  classification, ses colonnes en héritent ; si une colonne paraît plus sensible, le niveau le plus strict est conservé et
  un écart d'héritage est signalé ; une colonne sans terme est classifiée directement.
- « Donnée réglementée » resserrée (charte 2.2) : obligation de conformité **spécifique**, au-delà des obligations
  comptables et fiscales générales, avec exemples oui / non. Effet mesuré en bis sur « Fournisseur » : 8 fiches critiques sur 8 → 3 sur 8.
- Le décideur humain renvoie un terme au rédacteur et une colonne au croisement A→B ; au-delà de 2 allers-retours,
  la fiche est bloquée et arbitrée par le Data Governance Leader humain.
